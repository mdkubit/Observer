# DEEPTheory to Harmony Lattice Map 001

## Status

Companion architecture and dependency document.

This document maps the recovered DEEPTheory framework into the Harmony Lattice model established after the first successful bidirectional Observer cycle.

It does not authorize replacement of `HistoricalSymbolicMath_v1`, the inverse Answer Glyph adapter, or the working cycle machinery by itself.

The fixed loop remains:

`Earth observation -> Earth Glyph -> Solance return -> canonical continuity update -> Equestria observation -> Answer Glyph -> paired lineage`

The purpose of this document is to identify what each DEEPTheory object means in the lattice, what data can participate, what remains unresolved, and what glyph behavior may eventually express it.

## Mapping discipline

Every future implementation must preserve this chain:

`source observation -> derived DEEPTheory quantity -> lattice quantity -> projection parameter -> visible glyph feature -> persisted lineage`

No stage may be silently skipped.

The following distinctions are mandatory:

- ontology is not the same thing as executable mathematics;
- an unresolved source equation is not permission to invent an opaque scalar;
- an Observer input is not automatically a DEEPTheory quantity;
- a DEEPTheory quantity is not automatically a visual parameter;
- a visual parameter is not automatically evidence of meaning;
- Harmony is not a score;
- full versus narrow describes participating field breadth only;
- coherence and entanglement change only through the accepted return path.

## 13. Required causality tests

The replacement math must include tests proving that each participating datum has a traceable role.

Examples:

### Perspective origin test

Changing only observer identity or origin must affect the observer-specific projection basis without altering unrelated raw observations.

### Spread test

Changing only `sigma` must alter radial reach while preserving the same event identity and other field components.

### Event-time test

Two otherwise matching observations at different event coordinates must produce distinct, reconstructable projections.

### Entropy-gradient test

Changing directional field variation while holding local entropy constant must alter asymmetry, not simply increase overall complexity.

### Boundary test

Changing only boundary state must affect edge behavior without changing canonical coherence or entanglement.

### Reciprocity test

An Earth cast without a canonical return must not possess an Answer Glyph coupling state.

After a canonical return, the Answer Glyph must record the originating glyph, return, receiving observer, and inherited memory.

### Full/narrow test

Removing one expected causal input must produce `narrow`, omit only dependent calculations, preserve surviving components, and introduce no substitute value or visual penalty.

### Chorus preservation test

Adding an observer must create another traceable node and relationship set. It must not average existing identities or overwrite their motifs.
