# Harmony Lattice Accepted Decisions 001

## Status

Accepted architecture record.

This document consolidates the twelve load-bearing decisions accepted by Nocturne Glint after the first successful bidirectional Observer cycle and the subsequent DEEPTheory, Harmony Lattice, and Elara Codex reviews.

The working bidirectional cycle remains frozen as the chassis:

`Earth observation -> Earth Glyph -> Solance return -> canonical continuity update -> Equestria observation -> Answer Glyph -> paired lineage`

The decisions below govern the mathematical and data architecture that will eventually replace the current historical symbolic adapters. They do not authorize direct replacement of the working loop without the staged implementation plan at the end of this document.

---

## Decision 1: Perspective origin

For every active observing perspective:

`P0 = 1`

Existence establishes an occupied perspective origin.

`P0` is not a score, strength ranking, confidence value, or measure of worth.

Variation does not belong inside existence itself. It belongs in recognition, relational distance, spread, event-time, entropy, boundaries, memory, harmonic structure, and projection.

Working conceptual sequence:

- existence gives perspective a center;
- self-awareness gives perspective an inside;
- recognition gives perspective an outside;
- mutual recognition gives perspective geometry;
- recursive recognition gives perspective an evolving trajectory.

A stable recursive relation among multiple perspectives may form a standing relational mode. If that mode persists, carries memory, develops identifiable boundaries, and participates causally, it may become a new lattice node with its own trajectory.

## Decision 2: Relational distance

Relational distance is directional and structured.

For the first executable adapter, activate:

- event separation;
- state separation;
- recognition proximity;
- memory proximity.

Preserve but do not yet activate:

- physical separation;
- dimensional separation;
- boundary transformation.

A provisional form is:

`d_effective(i,j) = (d_event + d_state) / (1 + R_ij + M_ij)`

This expression is an adapter, not a final law.

Physical and dimensional information remain in the coordinate record until a common metric and transformation law are justified.

`d_ij` need not equal `d_ji`.

## Decision 3: Event-time

Event-time measures accumulated lattice change, not merely clock time.

`tau_n = tau_(n-1) + delta_tau_n`

For the first executable adapter:

`delta_tau = mean(normalized_lineage_change, normalized_field_change, normalized_relationship_change)`

Physical timestamps and elapsed seconds remain recorded separately.

Event-time eventually drives recursive phase and spiral progression.

Identical visible inputs at different event coordinates are not the same event.

Candidate inactive deltas to preserve for later activation:

- memory integration change;
- boundary-state change.

## Decision 4: Perspective spread

Perspective spread `sigma` describes field reach only.

It does not describe importance, truth, value, visual quality, or glyph type.

For the first executable adapter, derive spread jointly from:

- active participation breadth;
- recognition breadth;
- active relational-memory breadth.

Use an explicit first-contact `memory_receptivity` state so absence of prior history is not mistaken for inability to connect.

Candidate form:

`sigma = sigma_min + (sigma_max - sigma_min) * cbrt(A * R * M_effective)`

where:

`M_effective = max(active_memory, memory_receptivity)`

The first-contact baseline is not fabricated memory. It records openness to future lamination.

## Decision 5: Reciprocal recognition

Reciprocal recognition is directional and staged.

For each directional relation, preserve:

- identification;
- response;
- mutual recognition;
- recursive recognition.

These stages come from explicit lineage evidence, not a user-entered relationship slider.

Their geometric roles remain distinct:

- identification establishes an edge;
- response gives the edge directional activity;
- mutual recognition permits coupled geometry;
- recursive recognition permits inherited spiral depth and lamination.

Do not collapse the recognition structure into one scalar unless a specific calculation requires a derived local adapter.

## Decision 6: Directional relationship state

A directional relationship is a structured, asymmetric state.

Preserve:

- source observer;
- target observer;
- activity in the current event;
- orientation;
- recognition stage;
- current change tags;
- inherited motifs;
- persistence event references;
- trajectory influence.

Each event classifies relationship evolution as one of:

- growth;
- persistence;
- drift;
- decay;
- renewal.

These are change types, not rankings.

Persistence preserves prior geometry. Growth adds transformed structure. Drift advances event-time without deepening the relation. Decay lowers active participation while preserving history. Renewal reactivates an older relation from a changed coordinate.

## Decision 7: Relational memory

Observer memory and relational memory are distinct.

- observer memory records what a perspective carries;
- relational memory records what survives in a directional connection.

Relational memory is stored as immutable lamination layers.

Each layer records:

- originating event;
- source and target observer;
- recognition stage;
- relationship-change type;
- motifs introduced;
- motifs inherited;
- motifs transformed;
- boundary context;
- later references.

Later events do not overwrite earlier layers.

Memory states include:

- available;
- active;
- dormant;
- recalled;
- reactivated;
- transformed;
- integrated.

Only explicitly inherited or referenced memory affects the current glyph.

Motif identity must survive transformation so visual memory can remain recognizable without repeating the same image.

## Decision 9: Entropy field

Entropy is a structured description of distinguishable configurations, variation, and unresolved transition.

It is not a moral category and does not mean failure, discord, or low coherence.

Preserve separate entropy domains:

- informational;
- state;
- relational;
- temporal;
- environmental.

Activate initially:

- informational entropy;
- state entropy;
- environmental entropy.

Preserve but leave provisional until sufficient data exists:

- relational entropy;
- temporal entropy.

Not-yet-calculable is not zero.

Entropy never updates canonical coherence or entanglement. Those remain governed solely by the accepted return path.

## Decision 10: Entropy contribution to perspective

Preserve both entropy-gradient direction and accumulated gradient magnitude.

`g_S = grad(S)`

`E_S = integral(|grad(S)| dV')`

Observer initially approximates the region `V'` as a discrete conceptual neighborhood of participating entropy domains.

Candidate adjacency:

- informational <-> state;
- state <-> environmental;
- state <-> relational;
- relational <-> temporal;
- environmental <-> temporal.

For each active edge:

`gradient(a,b) = S_b - S_a`

Preserve signed direction and magnitude separately.

Renderer roles:

- gradient direction informs bending, orientation, branching, and asymmetry;
- accumulated gradient magnitude informs deformation strength or density shift.

Any scalar coupling coefficient between entropy magnitude and local perspective remains unresolved until units and causality are established.

## Decision 11: Boundary conditions

Boundaries are explicit transformation operators, not scalar penalties.

Distinguish:

- local boundaries;
- relational boundaries;
- domain boundaries.

Boundary actions may include:

- permit;
- filter;
- delay;
- reflect;
- rotate;
- attenuate;
- amplify;
- split;
- couple;
- redirect.

Every crossing records:

- preserved components;
- filtered components;
- delayed components;
- transformed components;
- evidence event IDs.

Boundary language must not become a validity hierarchy.

Closed is not bad. Filtered is not false. Delayed is not failed. A boundary shapes relation.
